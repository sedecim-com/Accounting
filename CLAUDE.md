# CLAUDE.md

El contrato completo para trabajar en este repositorio vive en [`AGENTS.md`](AGENTS.md) — léelo antes de tocar código. Este archivo no lo duplica; sólo apunta.

- **Qué es y para quién**: [`docs/SCOPE.md`](docs/SCOPE.md).
- **Cómo trabajamos** (plan → issue → PR → CI → review): [`docs/PROCESS.md`](docs/PROCESS.md).
- **Qué se ha entregado, y cuándo**: [`docs/HISTORY.md`](docs/HISTORY.md).
- **Antes de responder sobre el estado del plan**: no cites una cifra de memoria ni de un documento viejo. Corre `npm run plan:status` y `npm run catalogo:estado` — ver por qué en `docs/HISTORY.md`, donde un documento anterior citaba commits que ya no existen en `main`.
- **Lee la issue en la que estás trabajando** antes de escribir código. Si el plan parece equivocado, sigue `docs/PROCESS.md` §5: comenta y detente, no reinterpretes en silencio.
